Identifying and Removing Bloatware From a New Computer

7 min read · By Muhammad Zakria

A new computer rarely arrives with just an operating system — manufacturers and retailers commonly add trial software, branded utilities, and promotional apps that run in the background from the first boot. Some of this is genuinely useless to you; some of it, despite looking similar, actually matters. Here's how to tell the difference before you start uninstalling.

What counts as bloatware

  • Trial software for antivirus suites, office products, or games, usually time-limited and designed to convert you into a paying customer.
  • Manufacturer utilities that duplicate built-in OS features — a branded "PC optimizer," driver updater, or system cleaner that does roughly what Windows or macOS already handles natively, often with more aggressive upsell prompts.
  • Promotional shortcuts and app-store links for unrelated services, sometimes installed as tiles or icons rather than full running programs.
  • Background telemetry or "experience" services from the manufacturer, which send usage data back to them and sometimes trigger periodic pop-ups suggesting other products.

What looks like bloatware but usually isn't

  • Manufacturer driver and firmware update tools (like Dell Update, Lenovo Vantage's driver component, or HP Support Assistant's update function) — these often deliver hardware-specific driver updates that Windows Update doesn't cover, particularly for things like touchpad behavior, fingerprint readers, or battery charge thresholds.
  • Keyboard, touchpad, or display utilities tied to specific hardware features, like customizable function keys or color calibration on the display — removing these can disable functionality entirely rather than just removing an app icon.
  • Chipset and graphics drivers bundled as installers, which are core system software even though they arrived alongside other pre-installed extras.

The general rule: utilities tied to specific physical hardware features are usually worth keeping; general "optimization," trial, or promotional software usually isn't.

How to remove it safely

  • Uninstall through the standard method for your OS (Windows Settings > Apps, or macOS's Applications folder plus its installer's own uninstaller if one exists) rather than just deleting files, to avoid leaving orphaned files and registry entries behind — see our guide on uninstalling software completely.
  • Remove one thing at a time rather than mass-uninstalling everything unfamiliar at once, so if something breaks (like a touchpad gesture or fingerprint reader), it's easy to identify what caused it.
  • Check what a program actually is before removing it by searching its exact name — many manufacturer utilities have generic-sounding names that don't make their purpose obvious.
  • Use your OS's built-in tools with caution. Windows' "Reset this PC" option can reinstall a clean version of Windows, but depending on the option chosen it may also reinstall manufacturer bloatware from a recovery partition — a fresh install using official Windows installation media avoids this, though it also means manually reinstalling legitimate drivers afterward.

Preventing it from coming back or slowing things down further

  • Check your startup program list after cleaning up installed software, since some trial and promotional apps register themselves to launch automatically — see our guide on managing startup programs for how to review and disable these.
  • Decline optional installs during setup of any new software going forward — many installers include checkboxes (sometimes pre-checked) offering to also install an unrelated toolbar, trial antivirus, or browser change.
  • For a new computer, do this cleanup early, before you've customized settings or installed much else, so it's easier to tell what you added versus what came pre-installed.
If you're unsure whether something is safe to remove, search its exact program name plus "safe to remove" rather than guessing based on how unfamiliar or annoying it seems — a plain-looking name can still be tied to real hardware functionality.

Quick bloatware cleanup checklist

  • Separate promotional/trial software from hardware-specific manufacturer utilities before removing anything.
  • Uninstall one item at a time through the proper uninstaller, not by deleting files directly.
  • Check startup programs afterward for anything still launching automatically.
  • Decline optional bundled installs when setting up new software going forward.
  • When unsure about a specific program, look it up by exact name before removing it.
