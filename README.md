# WorksAsExplained

A static tech-explainer website hosted with **GitHub Pages**, covering simple, easy-to-understand articles on how everyday tech works.

🔗 Live site: [worksasexplained.com](https://worksasexplained.com)

## About

WorksAsExplained publishes short, plain-language articles explaining how common tech, apps, and devices work — organized into categories for easy browsing.

## Structure

```
├── index.html            # Homepage
├── about.html             # About page
├── contact.html            # Contact page
├── privacy-policy.html     # Privacy policy
├── terms.html               # Terms of use
├── articles/                 # Individual article pages
├── categories/                # Category listing pages
├── articles-data.js            # Article metadata used for search/listing
├── search.js                    # Site search functionality
├── style.css                     # Site styling
├── sitemap.xml                    # SEO sitemap
└── robots.txt                      # Search engine crawl rules
```

## Tech Stack

- Plain HTML, CSS, and JavaScript (no framework/build step)
- Hosted via **GitHub Pages**
- Monetized with **Google AdSense**
- Uses **Google Consent Mode** for GDPR/UK/Switzerland consent handling

## Deployment

This site deploys automatically via GitHub Pages whenever changes are pushed to the main branch. No build process is required — all files are served as-is.
